# Ama Brownie - E-commerce para Confeitaria Artesanal

![Project Status](https://img.shields.io/badge/status-online-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

Uma plataforma de e-commerce completa e moderna desenvolvida para a **Ama Brownie**, focada em oferecer uma experiência de compra fluida para clientes e um gerenciamento robusto para a administração.

O projeto resolve o desafio de vender produtos personalizáveis (como brownies com diferentes recheios e adicionais) mantendo o controle de estoque e precificação dinâmica.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando uma stack moderna e escalável:

* **Frontend & Framework:** [Next.js 14+](https://nextjs.org/) (App Router)
* **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **Banco de Dados:** [MongoDB](https://www.mongodb.com/)
* **ORM:** [Prisma](https://www.prisma.io/)
* **Autenticação (Admin):** JWT & Bcrypt
* **Gerenciamento de Estado:** React Hooks / Context API

## ✨ Funcionalidades Principais

### 🛍️ Para o Cliente
- **Cardápio Interativo:** Navegação fluida por categorias.
- **Personalização de Pedidos:** Modal avançado que permite escolher sabores, recheios e adicionais, com cálculo de preço em tempo real.
- **Carrinho de Compras:** Gestão de itens intuitiva.

### 🔐 Painel Administrativo
- **Gestão de Produtos:** CRUD completo com suporte a variações complexas de preço e disponibilidade.
- **Gestão de Pedidos:** Visualização e atualização de status dos pedidos recebidos.
- **Segurança:** Rotas protegidas para acesso exclusivo da administração.
